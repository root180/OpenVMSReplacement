# Reference and Standards

This folder tracks source and supporting material used to validate the GDPS hardware replacement design.

## Required reference set

- ALPHA Systems Storage Information (08AUG2025)
- 040ADV-25-C-0020 HPE Servers
- COOP2026 Senate Checklist
- May 2026 Internal Dry Run Checklist
- APDMS Security Design Document
- Alpha / APDMS Architecture Principles, Standards and Guardrails

## Purpose

These references support current-state hardware and storage traceability, HPE/CDW-G procurement, network and security boundaries, DCIAC / COOP recovery requirements, and server/storage engineering decisions.

## Authority rule

These supporting references do not redesign application behavior. POLLVAX remains the north star for business rules in the GDPS technology port.
