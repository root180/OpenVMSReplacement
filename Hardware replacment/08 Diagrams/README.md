## Diagram controls

- GDPS storage objects are labeled LUN00-LUN09.
- RAIDSET names may appear only as source-mapping references.
- Storage capacities shown for GDPS are minimum sizing floors unless explicitly stated otherwise.
- Architecture figures should use clean, flat infrastructure styling without shadows.
